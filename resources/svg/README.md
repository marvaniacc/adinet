# Local SVG icons (Streamline Colors)

Drop Streamline Colors SVGs here named after the nav glyph keys:
dashboard, lawyer, clients, request, appointment, review, payment,
report, specialty, city, availability, message, service, profile.

Licensing: Streamline Free / Colors icons are licensed CC BY 4.0 —

Until the matching files are added, `x-svg-icon` falls back to
Material Symbols so the UI never breaks.
